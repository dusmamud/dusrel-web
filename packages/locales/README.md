# packages/locales — scope doc only, no code yet

Shared locales — har web app (mail, drive, chat, meet)
aur Account Centre (account.dusrel.com) isi package se
apni bhasha lega, apni copy nahi banayega. dusrel.com
landing isme nahi hai — wo alag Astro site hai (dekho
`docs/27-production-urls-paths.md`).

Shuruwat ke locales: English (`en`) + Hindi (`hi`).
Default locale: English (`en`).

Poora spec `docs/26-shared-locales.md` me hai — locales list,
URL rule, detection order, missing-key fallback, key-parity,
ICU formatting, switcher aur nayi locale ki checklist.

Is folder me abhi koi code nahi hai — na dictionary file, na
config, na package.json. Wo sab tabhi banega jab user uske
liye alag se "code likho" bolega.
